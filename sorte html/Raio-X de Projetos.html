Raio-X de Projetos

Abre duas versões do mesmo projeto e mostra o que está ligado à Replit, as chaves expostas, as rotas que faltam no servidor, os arquivos que sumiram e o que mudou de uma versão para a outra.

Você está vendo dois projetos de exemplo (uma versão completa e uma “consertada” que cortou o servidor). Carregue os seus zips e eles substituem o exemplo.
A

Versão base

ex.: a 1.7 completa
B

Versão para comparar

ex.: a que corrigiu a tela azul
Tudo é lido no seu navegador. Nenhum arquivo sai do seu aparelho.

O que cada aba faz

Diagnóstico
Lista os problemas de um projeto: ligações com a Replit, chaves expostas, chamadas para rotas que não existem no servidor (a tela azul), arquivos importados que sumiram, pacotes faltando, variáveis de ambiente e código original escondido em arquivos .map.
Comparar
Mostra o que mudou de A para B: arquivos e pastas cortados, quanto código cada pasta perdeu, funções que sumiram ou apareceram. Clique num arquivo para ver as linhas que mudaram.
Histórico
Se o zip trouxe a pasta .git, lista cada alteração com data e descrição, e destaca as que falam em correção (fix).
