🚀 Guia de Instalação

Controle de Tokens e Custos - Sistema Completo

1 Preparar o Terminal

Primeiro, vamos abrir o terminal e navegar até o local onde você quer criar o projeto.

💡 Dica

Se você está no Windows, use o PowerShell ou CMD. No Mac/Linux, use o Terminal.

Escolha um local para o projeto:

Windows (PowerShell)
cd Desktop
Mac/Linux
cd ~/Desktop
⚠️ Importante: Você pode trocar "Desktop" por qualquer outra pasta. Exemplo: Documents, Projetos, etc.
2 Criar a Estrutura de Pastas

Agora vamos criar todas as pastas que o projeto precisa.

Copie e cole este comando:

Todos os Sistemas
mkdir controle-tokens && cd controle-tokens && mkdir js css lib && echo "Pastas criadas com sucesso!"

O que foi criado:

📁 Estrutura do Projeto
controle-tokens/
├── js/ (arquivos JavaScript)
├── css/ (arquivos de estilo)
├── lib/ (bibliotecas externas)
└── index.html (página principal)
✅ Se você viu "Pastas criadas com sucesso!" tudo está certo!
3 Criar os Arquivos CSS

Vamos criar os arquivos de estilo (CSS) que deixam o projeto bonito.

Arquivo 1: style.css

Windows (PowerShell)
New-Item -Path "css\style.css" -Force
Mac/Linux
touch css/style.css

Arquivo 2: dark-mode.css

Windows (PowerShell)
New-Item -Path "css\dark-mode.css" -Force
Mac/Linux
touch css/dark-mode.css
💡 Próximo Passo

Depois de criar os arquivos, você vai colar o conteúdo CSS em cada um deles. Vamos fazer isso na próxima tela!

4 Criar os Arquivos JavaScript

Agora vamos criar os arquivos JavaScript que fazem o sistema funcionar.

Criar todos os arquivos JS de uma vez:

Windows (PowerShell)
New-Item -Path "js\controle-tokens.js" -Force; New-Item -Path "js\graficos.js" -Force; New-Item -Path "js\notificacoes.js" -Force; New-Item -Path "js\exportacao.js" -Force
Mac/Linux
touch js/controle-tokens.js js/graficos.js js/notificacoes.js js/exportacao.js

Arquivos criados:

5 Criar o Arquivo HTML Principal

Este é o arquivo que você vai abrir no navegador. É o "coração" do projeto.

Windows (PowerShell)
New-Item -Path "index.html" -Force
Mac/Linux
touch index.html
✅ Arquivo criado! Agora vamos preencher com conteúdo.
6 Abrir no Editor de Código

Agora vamos abrir o projeto em um editor de código para colar os arquivos.

Se você tem VS Code instalado:

Todos os Sistemas
code .

Se não tem VS Code, use:

Windows (Bloco de Notas)
notepad index.html
Mac (TextEdit)
open -a TextEdit index.html
💡 Recomendação

Baixe o VS Code (é grátis): https://code.visualstudio.com/

7 Colar os Arquivos

Agora você vai colar o conteúdo de cada arquivo. Vamos fazer em ordem:

Ordem de Colagem:

⚠️ IMPORTANTE: Cole o index.html por último! Ele precisa dos outros arquivos.

Como colar:

  1. Abra o arquivo no editor
  2. Selecione todo o conteúdo (Ctrl+A)
  3. Delete tudo
  4. Cole o novo conteúdo (Ctrl+V)
  5. Salve (Ctrl+S)
8 Abrir no Navegador

Agora vamos testar o projeto abrindo no navegador!

Opção 1: Arrastar o arquivo

  1. Abra uma pasta no seu computador
  2. Navegue até a pasta "controle-tokens"
  3. Arraste o arquivo "index.html" para o navegador

Opção 2: Clicar com botão direito

  1. Clique com botão direito em "index.html"
  2. Selecione "Abrir com" → "Navegador"

Opção 3: Usar servidor local (recomendado)

Se tem Python instalado
python -m http.server 8000

Depois abra: http://localhost:8000

✅ Pronto! O projeto está funcionando!
9 Testar o Sistema

Vamos fazer um teste rápido para garantir que tudo está funcionando!

Teste 1: Calcular Custo

  1. Selecione uma IA (ex: Claude 3.5 Haiku)
  2. Digite tokens entrada: 250
  3. Digite tokens saída: 180
  4. Clique em "Calcular Custo"
  5. Veja o resultado aparecer

Teste 2: Modo Escuro

  1. Clique no botão "🌙 Modo Escuro"
  2. A tela deve ficar escura
  3. Clique novamente para voltar

Teste 3: Exportar Dados

  1. Clique em "Exportar CSV"
  2. Um arquivo deve ser baixado
✅ Se tudo funcionou, parabéns! Seu projeto está completo!
