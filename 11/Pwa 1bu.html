🔧 PWA Builder

Gera os arquivos de instalação para qualquer projeto virar PWA

📋 1. Informações do App
🎯 2. Tipo de Projeto
💡 O index.html será criado na raiz e redirecionará para a pasta automaticamente
📄 3. Cole o HTML do seu projeto
💡 Se já tem o HTML hospedado, pode deixar em branco e só baixar o manifest.json e service-worker.js
⚡ 4. Gerar Arquivos PWA
📖 5. Como instalar no Netlify/servidor
1
Baixe os 3 arquivos: index.html, manifest.json e service-worker.js
2
Coloque os 3 arquivos na mesma pasta — é obrigatório que fiquem juntos na raiz do site
3
Se for BUILD, coloque a pasta (dist, build, etc) na mesma raiz também
4
Suba para o Netlify Drop: acesse app.netlify.com/drop e arraste a pasta inteira
5
Acesse o link gerado pelo Netlify no celular → toque em "Adicionar à tela inicial" → pronto, instalado! ✅
⚠️ Importante: O site PRECISA estar em HTTPS para o PWA instalar. Netlify, GitHub Pages e Glitch já têm HTTPS grátis.
